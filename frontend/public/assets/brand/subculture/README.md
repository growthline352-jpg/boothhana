# BoothHana Subculture logo

The active header, footer and preview favicon reuse `/assets/categories/subculture-3d.webp`, the existing purple keychain/book/badge icon from the production category portal. Source: https://boothana.kr/assets/categories/subculture-3d.webp (copied unchanged on 2026-10-08). The Korean wordmark is HTML text in BrandLogo.tsx. The original parent brand logo is preserved.

The coral booth PNG below is a superseded proposal and is no longer referenced by the UI.

Created with the built-in image_gen tool (logo-brand), 2026-10-08. No CLI fallback used. Final prompt:

Use case: logo-brand. Create the final standalone symbol for BoothHana Subculture, a Korean site for discovering fandom characters, artists and convention booths. A warm, distinctive compact convention booth emblem: simple rounded coral awning with three broad scallops, two sturdy dark ink side pillars and a rounded coral counter, one bold four-point coral star centered inside the open booth. The booth is inviting and collectible, not a retail shopping bag. Flat graphic design, elegant rounded geometry, clear negative space, extremely clean edges, restrained coral #F36148 and deep charcoal #252630 only. Strong readable silhouette at 32px, no tiny details, no character faces, no additional decoration. Square asset, symbol fills about 88 percent of width and height with small equal transparent margins. Genuine transparent background. No gradients, glow, shadows, texture, mockup, background shape, lettering, words, watermark, or border. Only one centered logo symbol. This is the actual production header logo mark; the Korean wordmark will be typeset separately in HTML.
