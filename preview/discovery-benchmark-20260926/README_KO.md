# 부스하나 발견 홈 벤치마크

작성일: 2026-09-26

## 결론

부스하나 홈은 큰 카피로 브랜드 분위기를 설명하기보다 사용자가 바로 행사를 찾게 해야 한다. 추천 방향은 **Fever의 탐색 구조 + 이벤터스의 빠른 메뉴 + Eventbrite의 필터 + 하루곳의 일정 묶기**다.

## 기존 시안이 약했던 이유

1. 실제 행사보다 큰 문구가 먼저 보여서 사용자가 서비스의 양을 체감하기 어렵다.
2. 네 안이 시각적으로는 달라도 모두 히어로 다음 카드 목록이라는 같은 흐름이다.
3. 날짜, 지역, 무료 여부처럼 실제 선택에 필요한 정보가 첫 화면에서 약하다.
4. 추천 이유와 데이터 신뢰도가 보이지 않아 행사 포스터 모음처럼 느껴진다.
5. 저장 이후 무엇을 할 수 있는지 드러나지 않는다.

## 권장 홈 정보 구조

### 1. 상단 고정 탐색

- 로고
- 현재 지역: 서울·경기
- 통합 검색: 행사명, 장소, 장르
- 저장함
- 로그인

### 2. 서비스 핵심 탭

- 서브컬처
- 박람회
- 축제

탭을 바꾸면 아래 데이터와 추천 기준이 즉시 바뀐다.

### 3. 빠른 조건

- 오늘
- 이번 주말
- 다음 달
- 무료
- 가까운 순
- 목록 / 지도 전환

### 4. 첫 화면 콘텐츠

- 왼쪽: 이번 주 대표 행사 1개
- 오른쪽: 날짜가 가까운 행사 4개
- 바로 아래: 많이 저장한 행사 가로 목록

첫 화면 안에서 최소 5개의 실제 행사와 날짜, 장소, 비용 상태가 보여야 한다.

### 5. 두 번째 화면 콘텐츠

- 날짜별 일정 레일
- 지역별 행사 수: 강남, 성수, 마곡, 수원
- 새로 등록된 행사
- 마감 임박 행사

### 6. 저장 이후 가치

- 같은 날짜의 저장 행사를 자동으로 묶기
- 가까운 장소끼리 방문 순서 제안
- 일정 변경과 취소 상태 표시
- 행사 전날 다시 확인할 정보 제공

## 카드 기준

- 이미지 비율 3:2
- 날짜를 가장 먼저 읽게 표시
- 제목은 최대 2줄
- 장소와 지역은 한 줄
- 무료, 유료, 예매 필요, 현장 입장 중 하나를 명확히 표시
- 저장 버튼은 모든 카드의 같은 위치
- 추천 이유는 필요한 경우 한 줄만 표시

## 다음 시안의 시각 방향

- 밝은 중립 배경
- 기존 부스하나 파란색을 유일한 주 강조색으로 사용
- 포스터 색은 콘텐츠 이미지 안에서만 사용
- 큰 슬로건보다 검색과 실제 행사 우선
- 둥근 카드 남용 없이 이미지와 정보 간격으로 구분
- 데스크톱은 정보 밀도를 높이고 모바일은 가로 스크롤 목록으로 전환

## 다음 시안에서 제외할 것

- 화면 절반을 차지하는 추상 슬로건
- 디자인을 위한 영문 장식 문구
- 카드마다 다른 강조색
- 지도 중심의 첫 화면
- 사용 전에 취향 질문부터 요구하는 흐름
- 실제 기능과 관계없는 거대한 통계 숫자
