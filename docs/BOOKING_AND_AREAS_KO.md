# 예약 상태 및 서울 세부 지역 (0.2.8.7)

## 예약 상태

- `visitorGuide.tickets[].status`는 자료 확인 상태입니다. `bookingState`는 UNKNOWN / UPCOMING / OPEN / CLOSED / SOLD_OUT이며 선택 필드입니다.
- 공개 원문과 확인일이 있는 예매권에서만 상태를 표시합니다. 행사 취소·종료와 예약 접수 종료는 별개입니다.
- 한국 시간의 판매 마감 이후 사전예약 종료로 표시합니다. 날짜만 확인된 마감일은 다음 날 00시부터 종료로 판단하며, 당일 시작 시각을 모르면 예약 중이라고 단정하지 않습니다.
- 판매 기간이 없는 예약 중·예매 예정 관찰은 확인 당일에만 사용합니다. 부분 날짜나 미확인 예매권이 섞이면 일부 일정 상태로 표시합니다.
- 종료된 예약 링크는 안내 원문으로 유지합니다. 현장 입장 조건은 출처가 있는 FAQ에서 확인합니다.

## 서울 지역

- 실제 25개 구를 `event.districts` 배열로 보존하고 화면은 9개 권역을 복수 선택합니다.
- `region=SEOUL&areas=NORTHWEST,CENTRAL`처럼 목록·그룹 목록·캘린더에 같은 필터를 사용합니다.
- 검토된 개최 구가 있으면 이를 우선 사용합니다. 없는 기존 자료는 공개 주소의 행정구를 읽습니다.
- 주소·개최 구 미확인 행사는 서울 전체에 표시합니다. 행사 제목이나 주최자 주소로 개최지를 추정하지 않습니다.
- 여러 개최 구를 가진 행사는 선택한 권역 중 하나와 겹치면 표시합니다.
- 관리자 체크박스로 실제 개최 구를 수정할 수 있으며 경기 행사에는 서울 구를 저장할 수 없습니다.
- 수집기는 확인된 구를 채우되 기존 확정 지역을 덮어쓰지 않습니다. 새 자료는 기존 검토·공개 절차를 따릅니다.

## 검증

- 예약 마감 시각 및 날짜 경계, 확인일, 날짜별 부분 종료를 프런트엔드 테스트로 검증합니다.
- 실제 PostgreSQL에서 다중 장소, 기존 주소, JSON null, 미확인 주소 및 목록/그룹 건수 일치를 필수 릴리스 테스트로 검증합니다.
