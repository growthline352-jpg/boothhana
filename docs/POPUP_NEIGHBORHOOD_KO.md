# 동네별 팝업 탐색

2026-10-06. 로컬 수정·검증 완료, 기존 요청에 따라 통합 배포 대기 중이다.
운영 화면과 API는 아직 이전 버전이다.

## 변경 내용

- `/popups` 화면과 `/api/public/catalog/popups` API의 기본 공개 설정을 켰다. 팝업 홈·목록에 동네 탐색 진입 버튼을 제공한다.
- 기본 기간은 오늘부터 7일이다. 이번 주말·직접 날짜 선택을 제공하고 조회 기간은 최대 31일로 제한한다.
- 서울 전체, 성수·서울숲, 연남을 선택한다. 수동 장소 등록이 없어도 **공개 스냅샷의 명확한 주소**에서 동네를 분류한다.
- 성수동·성수일로·성수이로·서울숲길·연무장길과 해당 숫자 골목, 연남동 명시 주소를 사용한다. 구 이름이나 여러 동네에 걸친 도로만으로 동네를 추정하지 않는다. 그 밖의 서울 팝업은 서울 전체에서 제공한다.
- 목록 조회에서 지도 공급용 주소가 함께 내려온다. 이전 수동 좌표는 현재 공개 주소와 정확히 같은 경우에만 사용한다. 새 주소로 공개하면 이전 좌표를 즉시 제외한다.
- 좌표가 없는 실제 도로명·지번 주소는 지도 선택 시 기존 서버 카카오 주소 API로 조회한다. 층 정보를 정리하고 같은 주소의 요청을 합치며 동시 조회는 4건으로 제한한다. 기존 제공자 캐시·일일/분당 사용량 제한을 유지한다.
- 별도 카카오 브라우저 SDK·JavaScript 키 없이 일정 지도와 동일한 Leaflet 기반 지도를 사용한다. 지도 코드는 지도 선택 시에만 불러온다.
- 가까운 팝업은 지도 표식을 묶고 개별 행사 선택을 제공한다. 같은 회차의 여러 장소도 해당 회차 카드에 연결한다.
- 지도 선택→해당 카드, 카드 위치 선택→지도와 선택된 위치로 이동한다. 모바일에서도 같은 동작을 제공한다.
- 주소·좌표가 없거나 조회가 실패한 행사도 목록에 유지한다. 확인되지 않은 위치를 동네 중심점으로 표시하지 않는다. 실패한 위치는 다시 확인할 수 있다. 지도 배경 실패 시 목록·길찾기 링크를 계속 사용한다.

## 통합 배포 시 적용

1. SQL027 장소/그룹 테이블이 적용된 서버에 새 API를 배포한다. 이번 수정은 추가 SQL을 요구하지 않는다.
2. API 환경의 `POPUP_EXPLORE_ENABLED=true`, Vercel 빌드 환경의 `VITE_POPUP_EXPLORE_ENABLED=true`를 적용한다. 두 변수가 없으면 새 기본값은 공개다. **기존 환경에 `false`가 있으면 기본값을 덮어쓰므로 함께 변경해야 한다.**
3. 프런트엔드를 새로 빌드·배포한다. 서버의 기존 카카오 REST 주소 조회와 지도 타일 연결을 확인한다. `VITE_KAKAO_MAP_KEY`는 필요하지 않다.
4. `https://popup.boothana.kr/popups` 진입 버튼, 유효한 날짜의 공개 API 200, 성수 주소 기반 목록, 실제 좌표, 모바일 선택 동작을 확인하고 배포 기록에 남긴다.
5. 긴급 중단은 화면/API 환경을 각각 `false`로 설정하고 재배포한다. 일반 팝업 목록과 개인 저장 내용은 별도로 유지한다.

## 검증

- 프런트엔드 58파일 318테스트 통과, 타입 검사·로컬 빌드 성공. 변경한 화면/위치/공개 설정 파일 린트 오류·경고 0개.
- 별도의 localhost PostgreSQL 16 클러스터에 실제 SQL001~028을 적용했다. 제한된 런타임 계정으로 운영 연동 17건, 공개 차단 1건, 장소 제공자 8건, 총 26건을 건너뜀 없이 통과했다.
- 운영 연동 테스트는 팝업 API 공개 설정을 별도로 켜지 않아 새 기본값으로 익명 200을 확인한다. 장소 미등록 주소 분류·미공개 변경 비노출·주소 변경 후 좌표 제외·회차별 카드와 여러 장소·잘못된 기간/동네·비팝업/제외 자료 차단을 검증한다.
- 로컬 브라우저 행사 자료는 공개 API의 읽기 전용 스냅샷이다. 지도 주소 조회는 운영의 기존 공개 읽기 API를 사용했다. 운영 데이터 변경이나 배포는 하지 않았다.
- 성수 공개 행사 6건, 서울 전체 21건 중 주소가 있는 20건의 위치를 지도에서 확인했다. 주소 없는 1건은 목록에 유지했다. PC/모바일 가로 넘침, 표식 묶음 선택, 카드→지도 복귀, 빈 동네→서울 전체 복귀를 확인했다.
- 주소 조회 503과 지도 타일 실패를 주입했을 때 21개 카드를 모두 유지하고 실패 안내·위치 재시도를 제공했다. 주소 연결을 복구한 뒤 같은 화면의 재시도로 20개 위치를 회복했다.
