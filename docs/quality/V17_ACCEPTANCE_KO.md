# v17 실환경 수락검사 · 현재 모두 미실행

이 문서는 코드 변경 후 운영자가 실제 환경에서 수행할 체크리스트입니다. 코드 단위검사/모의 API의 통과를 여기의 실연동 통과로 옮기지 않습니다. 결과마다 실행일·환경·실행자·증거 경로를 기록합니다. 개인정보·토큰을 증거에 남기지 않습니다.

## 실제 행사 하나로 끝까지 확인

동의/사용 권한을 확보한 실제 행사 하나를 선정합니다. 운영 중 이용자 데이터가 아니라 별도 테스트 환경에서 진행합니다.

1. 공개 원문을 수집하여 행사·참가 부스·판매 근거·출처·수집 누락을 확인합니다. 자료 미확보는 미참가/미판매로 단정하지 않습니다.
2. 운영자가 검토하고 이미지의 사용 조건과 공유 미리보기 이용 범위까지 확인합니다. 승인 전 이미지는 공개되지 않아야 합니다.
3. 행사·부스·상품을 공개하고 웹 목록/상세/raw HTML에서 서로 맞는 정보를 확인합니다.
4. 비회원 및 회원으로 저장하고 검색·메모·날짜·배치도·공유 QR의 동작과 비공개 정보의 미노출을 확인합니다.
5. 실제 운영일 기준 방문 기록을 남깁니다. QR을 열었다는 이유만으로 방문 처리되지 않아야 합니다.
6. 행사 종료 후 보관함에서 다시 찾고 현재 재확인 상태와 과거 정보를 구분하는지 확인합니다.
7. 이미지 권리 또는 행사 공개를 철회하여 새 요청과 재검증 화면에서 노출이 중단되는지 확인합니다. 외부 플랫폼의 캐시/이미 내려받은 파일을 완전히 회수하는 기능이라고 안내하지 않습니다.

수집 누락 수·운영 검토 시간·이미지 승인 대기·오류·다시 찾기 성공을 기록합니다. 점수나 목표치를 측정 없이 만들어 넣지 않습니다.
