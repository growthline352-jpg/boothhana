# 통합 나들이 일정과 SEO 보완

`/outings`는 공개 팝업·박람회·축제를 함께 탐색하는 일정 화면입니다. 홈 포털에서 진입하며, 처음에는 실제 공개 행사를 표시합니다. 예시 행사는 사용자가 선택할 때만 표시하고 예시 일정으로 구분합니다.

새 일정과 보관함은 해당 브라우저의 `boothhana.outings.local.v1`에 저장됩니다. 파일 내보내기·가져오기를 지원하며 계정 동기화·공동 편집은 제공하지 않습니다. 기존 `/itinerary`, 공유 일정 및 계정 저장 데이터는 그대로 유지하고 푸터에서 연결합니다.

검색은 `/outings` 소개만 색인 대상으로 제공하며 `view=plans`, `view=saved`, 지도와 편집 상태는 noindex입니다. 메타데이터에는 개인 일정이나 보관함을 포함하지 않습니다. 공개 행사 API는 기존 운영 API 클라이언트를 사용합니다.

행사·부스의 검색용 HTML은 전체 운영일, 부스 배정, 참가자, 공식 링크와 공개본 갱신 시점을 제공합니다. 명시적으로 이번 행사 근거가 있는 상품만 현재 상품으로 표시합니다. 종료된 회차는 기록을 보존하고 같은 지역의 예정 행사 탐색으로 연결합니다. 기본 목록은 예정 행사를 날짜순으로 읽되 전체 행사 목록의 페이지와 섹션별 URL은 보존합니다.

DB·백엔드·수집기 변경은 이 릴리스에 포함하지 않습니다. 검색 노출·트래픽 회복 여부는 배포 후 Search Console에서 별도로 관찰해야 합니다.

릴리스 CI의 OS는 Ubuntu 24.04로 고정합니다. `ubuntu-latest`가 Ubuntu 26.04를 제공하면서 기존 Playwright 1.57의 브라우저 설치가 실패한 문제를 해결하며 검사 항목은 유지합니다.
