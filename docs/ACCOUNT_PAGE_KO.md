# 내 정보 화면

경로: `/account`. 햄버거 메뉴와 모바일 하단 메뉴에서 접근한다.

## 정보 구조

1. 계정 정보: 실제 AuthProvider의 표시 이름과 권한. 로딩·인증 오류·비회원·회원 상태를 구분한다.
2. 내 활동: 보관함(메모·방문 기록), 기기별 오프라인 저장본, 예약 내역. 기존 기능으로 연결하며 별도 목록을 복제하지 않는다.
3. 행사·부스 운영: 소유권 인증 및 승인 정보 관리. 크리에이터·관리자 작업 공간은 해당 권한일 때만 노출한다. 실제 접근 권한은 기존 서버가 검증한다.
4. 고객지원: 문의·신고 답변, 행사 추가 요청.
5. 저장 정보 안내 및 로그아웃: 계정/기기 저장 차이를 안내하고 실제 로그아웃 동작을 사용한다.

계정 유형과 행사·부스 소유권 인증은 서로 다른 개념임을 표시한다. 이메일·전화번호·가입일·로그인 제공자는 현재 User 응답에 없으므로 추측해서 노출하지 않는다. 프로필 변경/회원 탈퇴 API도 없으므로 가짜 편집 버튼을 만들지 않는다.

## 개인정보와 이후 작업

- 공개 검색 메타데이터는 `내 정보 | 부스하나`, noindex이며 실제 계정 이름은 메타데이터에 포함하지 않는다.
- 개인 정보 API를 추가 호출하지 않고 기존 인증 상태만 사용한다. 오류/로딩 시 이전 사용자 정보를 숨긴다.
- 프로필 수정과 회원 탈퇴를 추가하려면 서버 API, 권한 검증, 탈퇴 시 예약·보관함·소유권 처리 정책을 먼저 정의해야 한다.
- 이번 작업은 로컬 구현이며 운영 배포하지 않았다.

## 검증

회원/비회원/인증 오류/권한별 SSR 테스트를 추가했다. 프론트 테스트 55개, SEO 테스트 17개, 프로덕션 빌드 통과. 브라우저 시각 검증은 아직 수행하지 않았다.
