# 부스하나 v20 · 코드리뷰 오류 수정본

2026-09-18 · 입력 v19 · **운영 배포 승인 아님**

## 먼저 확인

추가 SQL이 없으며 **SQL001~016, 의존성 버전/잠금 파일, 서버·수집기 코드는 v19와 동일**합니다. 서울·경기, 인천 제외, 서브컬처·박람회·축제 범위를 유지합니다.

**v19의 유효한 오프라인 사본은 재다운로드를 강제하지 않습니다.** DB버전2/사본형식19는 유지하고 기본 화면 캐시만 v20으로 갱신합니다. v18 이하에서 넘어오는 경우에는 이전 형식 전환에 따른 재다운로드가 별도로 필요합니다. 회원 보관함이나 서버 데이터를 초기화하지 마세요.

## 이번 수정

보안 토큰의 JSON 본문 지연에도 시간제한 유지, 확인된 계정 변경/로그아웃 이후 이전 요청의 재전송·응답 적용 차단, 실패한 IDB open의 늦은 업그레이드에 의한 삭제 방지, 동일 행사 방문일 변경 시 오래된 다운로드 중단을 반영했습니다.

신규 13개는 수정본에서 통과하고 원본 v19에서는 12실패·1통과했습니다. 이것을 독립 결함 12개 또는 실제 브라우저 통과로 해석하지 마세요. 기존 독립 검사와 수집기170개도 통과했지만 정식 빌드·실DB·브라우저 수락검사는 완료하지 못했습니다.
