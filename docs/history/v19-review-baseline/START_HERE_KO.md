# 부스하나 v19 · 코드리뷰 오류 수정본

2026-09-18 · 기준 v18 전체 소스 · **운영 배포 승인본 아님**

## 먼저 확인

**서버 신규 SQL은 없습니다. SQL001~016과 의존성/잠금 파일은 원본 v18 그대로입니다.** 다만 기기의 임시 오프라인 저장 형식은 변경했습니다. v18에서 내려받은 행사 사본은 다시 내려받아야 하며, 회원·비회원 보관함의 기존 저장/메모와 서버 데이터는 이 정리 대상이 아닙니다.

현재 범위: 서울특별시·경기도, 인천 제외. 서브컬처·박람회·축제의 기존 15개 하위 분류. 명시적으로 받은 자료의 읽기 전용 오프라인 열람(`/offline/index.html`). 예약·POS와 수집 카탈로그의 구분 및 이미지 별도 허용 정책 유지.

## 이번 수정

삭제 후 늦은 다운로드가 되살리는 문제, 이전 계정 작업/권한 재확인의 잘못된 사본 적용, 오래된 판매 요약·출처표시 유지, 다른 탭의 삭제·철회 미반영, 검색 중 Blob URL 누적, 상세 화면 만료 미반영을 수정했습니다. 실제 배치도 다운로드 여부로 완료 상태를 판단하고, 행사 이동/선택 목록 로딩/새 worker 설치 경계를 보완했습니다.

새 회귀 검사18개는 수정본에서 통과했고 동일 검사를 원본에 실행하면 17실패·1통과였습니다. 기존 수집기170개 및 지역·분류·인증·보관함 등의 독립 검사도 통과했습니다. 이는 실제 모바일/SQL/브라우저 통과가 아닙니다.

## 적용·검증

1. [변경 내역](docs/release/V19_CHANGES_KO.md)과 [검사 결과](TEST_RESULTS_KO.md)를 확인합니다.
2. [적용·수락 절차](docs/deployment/FULL_V19_KO.md)에 따라 스테이징에서 정식 빌드/DB/브라우저를 검증합니다. v17 이하에서 올라오는 경우 기존 SQL016 필요 여부를 별도 확인합니다.
3. 오프라인 정적 파일 전체를 같은 버전으로 배포하고, 사용자에게 행사 전에 인터넷 연결 상태에서 이전 탭 종료 → 재접속 → 행사 다시 저장을 안내합니다.
4. 실제 휴대폰 비행기 모드/새 탭/재실행/계정 전환/이미지 CORS/공개 철회를 검증합니다. 운영 계정·배포·수집은 이번 작업에서 실행하지 않았습니다.

현재 검사 명령은 `python verification/run_checks.py`입니다. 실환경 게이트는 `verification/v19/release_gate.py`이며 준비되지 않거나 실패하면 NOT_READY를 남깁니다. 상세 현재 로그는 `verification/v19/results/`, 무결성은 `SHA256SUMS.txt`입니다. v18 안내 원문은 `docs/history/v18-review-baseline/`에 보존했습니다.
