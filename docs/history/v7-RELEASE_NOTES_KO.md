## 호환·범위

필수 DB는 SQL 007입니다. 배치·백엔드·프런트는 같이 업데이트합니다. 외부 URL·기존 API base는 유지합니다. 명단/판매 단계의 JSON은 schemaVersion=5이며 identity는 근거가 없으면 null입니다.
기존 v4 request ID의 읽기·정상 동일 요청 재전송은 서버가 호환 처리하지만, Python v4 디스크 체크포인트를 v5 작업으로 변환하지 않습니다. 새로운 작업 폴더를 사용합니다.
이미 발생한 중복을 자동으로 합치지 않습니다. 현재 공개 스냅샷과 이미지·검토 관계를 깨지 않기 위함입니다. 신규 모호 매칭은 PARTIAL+검토 필요로 남깁니다.
전체 소스를 처음부터 다시 만든 것이 아니며 대규모 서비스 분리·예약/POS 정책 변경·새 행사 유형 확장은 포함하지 않습니다.
