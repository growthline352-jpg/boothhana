# 부스하나 전체 소스 v9 · 적용 안내

2026-09-17 · 기준: BoothHana2-full-v8-20260917.zip

이 ZIP은 이전 기능과 사용자 과업 중심 UX 보완을 통합한 **전체 소스**입니다. 패치/전체본 생성기가 아니며 이전 적용 스크립트를 다시 실행하지 않습니다.

## 반영과 배포

1. 기존 코드와 DB를 백업하거나 커밋합니다. 새 브랜치에서 압축 안 `BoothHana2`의 **내용물**을 저장소 루트에 반영합니다. 폴더를 한 겹 더 만들지 않습니다. 별도 로컬 변경은 비교해서 합칩니다.
2. 실제 `.env`, `.git`, 수집기 `config.local.json`, Codex 인증은 유지하고 공개 Git에 업로드하지 않습니다.
3. **v8 SQL 009까지 적용된 DB라면 추가 SQL은 없습니다.** 기존 JSON 컬럼에 선택적인 개최 상태를 보관합니다. 신규 DB는 001~009를 순서대로 적용합니다. `database/dev`는 운영용이 아닙니다.
4. 프런트엔드·백엔드·수집기를 함께 업데이트합니다. 기존 결과에 상태 필드가 없으면 UNKNOWN으로 처리합니다. 새 CLI 실행은 상태를 명시하도록 질문하되, 출처가 없으면 확정하지 않습니다.
5. 실제 의존성을 설치한 환경에서 전체 빌드/테스트 후 스테이징으로 확인합니다. 이번 작성 환경은 전체 React/Spring 빌드를 완료하지 못했습니다.
6. 주간·배치도 보완 스케줄은 기존과 같습니다. 실행 중에는 소스를 바꾸지 말고 배치 종료 후 업데이트합니다. 이미 등록한 일정을 다시 설치할 필요는 없습니다.

```powershell
cd frontend
pnpm install --frozen-lockfile
pnpm lint
pnpm build
cd ../backend
.\gradlew.bat test
.\gradlew.bat bootJar
```

## 방문자 화면

- `/discover`: 기존 3개 분야 탭. 박람회·축제에 준비 중 표시. 주말·다음 달·직접 날짜 범위를 선택할 수 있습니다.
- `/discover/{id}`: 행사 요약·입장 조건 → 공통 방문일·전시관·검색 → 참가 부스/배치도/행사 안내.
- `?day=YYYY-MM-DD&hall=...&q=...&view=map&focus=...&booth=...`: 확인된 공개 행사·부스의 탐색 맥락만 주소에 보관합니다. 존재하지 않거나 비공개인 부스는 안내하며 임의 연결하지 않습니다.
- 상품 보기: 날짜에 맞는 위치, 한줄요약, 이번 행사 상품, 상시·과거 참고를 나눕니다. 품절/취소/미확인 경고는 그대로 표시합니다.

## 관리자 화면

`/admin/subculture`에서 실제 운영 기간·개최 상태·개별 상품·지도 적용일을 일반 폼으로 수정합니다. JSON/버전 해시는 고급 상세로 내립니다. 수정 없이 검토만 하면 수집값을 고정하지 않습니다. 수동 수정값을 해제하는 기능도 유지합니다.

미저장 변경이 있으면 화면/탭 이동을 확인하고, 저장 전 행사 공개본 갱신은 막습니다. 검토·이미지 사용 승인·지도 공개·행사 공개를 자동 일괄 승인하지 않습니다.
