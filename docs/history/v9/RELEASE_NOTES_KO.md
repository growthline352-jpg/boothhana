# v9 릴리스 안내

# 사용자 과업 중심 UX 보완 v9

이 문서는 구현 범위입니다. 실제 사용자 테스트·운영 지표·실제 React 앱의 E2E 성공을 뜻하지 않습니다.

| 점검 | 이번 구현 |
|---|---|
| U01 개최 상태 | `operationStatus`로 UNKNOWN/SCHEDULED/CANCELED/POSTPONED/RESCHEDULED와 안내·원문·확인일을 수집·검증·편집·공개합니다. 취소·연기·일정 변경은 날짜 표시보다 우선합니다. 기존 경고만 있는 데이터는 확정 취소로 추측하지 않고 ‘방문 전 안내 확인’을 표시합니다. |
| U02 방문일 | 실제 운영일을 열거하고 휴무일은 채우지 않습니다. 오늘 또는 다음 운영일을 기본으로, 명시 선택을 우선합니다. 목록·검색·배치도·드로어에 같은 방문일과 전시관을 적용합니다. 날짜·홀 미확인 참가자는 별도 경고로 유지합니다. |
| U03 찾기와 위치 | 참가 부스·작가·상품 검색을 공유합니다. 부스명·판매요약·번호를 함께 보여주고 ‘지도에서 보기/상품 보기’를 나눕니다. 연결된 영역은 선택 시 확대·중심 이동하며, 연결 근거 없는 위치는 추측하지 않습니다. |
| U04 모바일 배치도 | 자연스러운 도면 비율, 전체화면 native dialog, 두 포인터 확대/끌기, 전체보기 복귀. 미연결 영역은 빗금·선·텍스트 범례를 함께 표시합니다. 작은 도형을 왜곡하는 대신 검색 목록으로 선택할 수 있습니다. |
| U05 행사 진입 | 날짜·시간·장소·입장 조건·확인된 안내 링크를 앞에, 긴 안내/배치도/참가 목록은 세 보기로 나눕니다. 공개된 서울 주소가 있을 때만 장소 지도·주소 복사를 제공합니다. 예매 링크나 비공개 주소를 만들지 않습니다. |
| U06 복귀·공유 | 방문일·홀·검색·보기·선택 부스가 URL에 보관됩니다. 새 창 공유 링크도 해당 공개 부스를 엽니다. 앱 안에서 연 드로어는 뒤로 가기로 닫고 직접 링크는 사이트 밖으로 나가지 않게 닫습니다. 동일 앱 세션 내 목록 복귀 스크롤을 데이터 로드 뒤 복원합니다. 지도는 보기 전환/드로어 중 마운트를 유지합니다. |
| U07 상품 정보 위계 | 상품명·가격을 먼저 보여주되 행사 관련성·품절·취소·재확인 경고는 유지합니다. 반복 출처·가격 조건은 접기, 상시·과거·미확인 품목은 별도 참고 묶음입니다. 실시간 재고라고 표시하지 않습니다. |
| U08 예외 동선 | 지도 실패 시 재시도/부스 목록/공식 안내를 제공합니다. 상태를 확인할 수 없는 저장 지도는 안전한 대체물로 간주하지 않습니다. 미발견/미연결/검색0건을 실제 미참가로 표현하지 않습니다. |
| U09 날짜 탐색 | 이번 주말·다음 달·날짜 범위를 추가합니다. 유효하지 않거나 뒤집힌 기간은 입력 오류로 안내하며 API 조회를 막습니다. 카드의 다음 방문일을 상세로 넘깁니다. |
| U10 메뉴 | 서브컬처·박람회·축제 3탭 유지, 후자 둘은 준비 중 표시. 예약 기능과 비로그인 정보 탐색을 구분하고 로그인은 서비스 메뉴에 둡니다. |
| U11 무이미지 정보 | 상품 이미지가 없으면 압축 카드, 승인된 부스컷/상품/로고 자산이 있으면 목록 썸네일. 미승인 외부 후보 이미지는 자동 로드하지 않습니다. |
| U12 운영자 | 상품/가격/상태/실제 운영일/지도 적용일은 폼·달력으로 편집. 다음 할 일, 미연결 영역 빠른 선택, 미저장 이탈 확인. 해시·JSON·기술 오류는 상세로 내립니다. |

## 구현상의 구분

- 달력상 운영일은 현재 시각의 영업 여부와 다릅니다. 개최 상태는 원문 근거를 보관하지만 자동으로 사실을 보증하지 않습니다. 관리자 공개 승인과 기존 공개 스냅샷 규칙을 유지합니다.
- 새 `operationStatus`는 기존 JSON 컬럼에 저장하므로 SQL 010은 없습니다. 구버전 결과도 읽으며, 확정 상태의 원문 URL·확인일·안내가 빠지면 저장 검증에서 거절합니다.
- 목록·지도는 공개된 정보만 사용합니다. 배치도 API 오류 시 이전 저장 이미지를 무조건 대신 띄우지 않습니다. 직접 원문 링크는 방문자가 최신 회차·날짜를 확인해야 합니다.
- 공유 링크는 방문 맥락·부스를 보존하며 픽셀 단위의 확대율까지 URL에 저장하지는 않습니다. 앱 세션의 보기 전환/드로어에서는 지도 상태를 유지합니다. 서버 권한이 철회되거나 공유된 날짜가 바뀌면 재확인 안내가 나옵니다.
- 원문 운영일 배열/부스 위치/공개 날짜를 임의 합치지 않습니다. 날짜를 확인할 수 없는 부스를 ‘참가 확정’이나 ‘미참가’로 바꾸지 않습니다.
- 관리자 JSON 기능은 고급 메뉴에 남아 있습니다. 저장값이 잘못되면 서버의 기존 검증·revision 검사로 거절합니다. 이미지 권한이나 상품의 행사 관계를 자동 승인하지 않습니다.
- 관심 부스/회원 찜, 현위치, 최단 경로, 실시간 재고, 박람회·축제 수집, 새 예약·결제 기능은 추가하지 않았습니다.

## 주요 변경 파일

`features/visit/`의 방문일/주소/상태/공유/스크롤/미저장·일반 편집 모듈, `CatalogPublicPage`, `BoothDrawer`, `Shared`, `InteractiveFloorPlans`, `PlanCanvas`, `viewport`, `DiscoveryPage`, `browse`, `PublicLayout`, `CatalogAdminPage`, `FloorplanAdmin`.

서버는 `CollectionModels/Rules`, `CatalogService`의 행사 수정 허용 필드를 확장했습니다. 수집기는 행사 JSON 스키마와 프롬프트·상태 검증, live 출력 규격 준비만 바꿨고, 단계 순서·기간 예산·스케줄은 유지했습니다.

## 실서비스 수락 기준

1. 두 날짜에 위치가 다른 부스: 방문일 변경 후 목록·검색·지도·드로어 위치가 일치하고 공백 날짜가 생기지 않아야 합니다.
2. 부스 링크 새 창 열기, 앱에서 모달 연 뒤 뒤로 가기, 목록 복귀 시 검색·페이지·스크롤. 비공개/삭제 부스 링크는 안내합니다.
3. 실물 휴대폰 두 손가락 확대·끌기·취소, 전체화면/Escape/키보드 초점 복귀. 공개된 실도면에 좌표가 일치해야 합니다.
4. 확정 취소/연기는 목록·상세·드로어에서 경고가 우선하고, 변경된 상태의 공개 승인이 필요함을 관리자에게 확인합니다.
5. 상품 이름/가격/품절/취소/행사 관계가 보이며 상시 상품을 현장 판매 확정으로 읽지 않아야 합니다.
6. 지도 네트워크 오류·권한 철회·폐기 도면: 다른 탐색 경로는 제공하되 오래된 연결을 다시 띄우지 않습니다.
7. 상품/운영일/지도 날짜 수정 후 미저장 탭 이동·브라우저 이동 확인. 저장 시 최신 수집값과 수동값/공개 상태의 기존 정책 유지.

기술 구현 참고: React Router useSearchParams/useBlocker/ScrollRestoration 공식 문서, MDN Pointer Events pinch zoom gestures. 이 문서를 확인한 것은 실제 프레임워크 빌드 성공을 뜻하지 않습니다.
