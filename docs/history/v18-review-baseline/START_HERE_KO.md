| DB | **SQL016 추가**. 기존 데이터/식별자/예약·POS/기존보관함 유지 |

**적용은 백업 → SQL016(기존001~015 다음) → 백엔드·프런트·수집기 동시버전 → 실환경 검증 순서입니다.** 이전 문서의 ‘SQL016 없음’은 v17 이력이며 현재 적용하지 않습니다.

원본 ZIP이나 운영 DB/계정/예약작업/GitHub/배포는 변경하지 않았습니다. 실제 새 행사 데이터를 수집·공개한 결과물은 아니며 코드·검증 도구를 반영한 전체 소스입니다.

오프라인 주소는 `/offline/index.html`입니다. 모든 웹페이지가 오프라인인 것은 아닙니다. 방문 전 자료와 기본 파일의 저장이 완료돼야 하며 일반 홈이 아닌 오프라인 주소로 들어갑니다. 초기 한도는 7일·최대5행사·합계60MiB입니다. 이미지 기본 허용=false이므로 관리자가 근거를 확인하고 체크하기 전에는 텍스트만 저장될 수 있습니다. 저장된 개인 관심표시는 이 기기 사용자에게 보일 수 있습니다.

축제 시간표 전용 화면, 실시간 혼잡·재고·알림, 오프라인 구매/수령 상태 변경·서버 동기화는 이번 범위가 아닙니다. 공식 예약·수령 기록과 외부 수집 상품은 연결된 것처럼 표시하지 않습니다.
