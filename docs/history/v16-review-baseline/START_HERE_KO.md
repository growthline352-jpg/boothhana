## 적용

1. 기존 코드와 DB를 백업하고 새 브랜치에서 비교합니다. 압축 안 `BoothHana2`의 **내용물**을 저장소 루트에 반영합니다. `.git`, 실제 `.env`, 수집기 설정·Codex 인증은 보존하되 Git에 올리지 않습니다.
2. **v15의 SQL015까지 적용한 DB라면 추가 SQL이 없습니다. SQL016은 만들지 않았습니다.** 오래된 DB는 [DB 검토표](docs/deployment/V16_DATABASE_REVIEW_KO.md)에서 미적용분을 확인합니다.
3. **프런트엔드와 백엔드를 함께 업데이트**합니다. 새 화면은 공개 대상 200개 조회와 상품 확인 상태 응답을 사용합니다. 새 프런트와 이전 30개 제한 서버를 섞지 않습니다.
4. 실제 환경에서 의존성 설치·빌드·DB·로그인·브라우저·공개 철회 회귀를 수행합니다. 명령과 전용 테스트 DB 규칙은 [배포 검증](docs/deployment/FULL_V16_KO.md)을 따릅니다.
5. 기존 기기 보관함 키와 메모를 유지합니다. 회원의 기기 기록을 자동 가져오기하지 않습니다. 방문일을 추정해 일괄 수정하지 않습니다.
6. 기존 CLI 수집·일요일03시 전체수집·월~토04시 배치도 보완 설정은 그대로입니다. 수집기 업데이트/스케줄 재등록은 이번 변경만으로 필요하지 않습니다.
