## 먼저 확인

**이번 동작 변경은 프런트5개 파일입니다.** v21에서 올라올 때 서버·수집기 재배포나 추가 SQL은 필요하지 않습니다. SQL001~016, 의존성/잠금, 서울·경기(인천 제외), 세 분야15분류를 유지합니다. v20 이하에서 건너뛰어 올라오면 기존 v21 서버 수정도 포함해야 합니다.
