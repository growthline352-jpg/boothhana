# v10 전체 디자인 개선

## 문제와 변경

| 기존 상태 | 개선 |
|---|---|
| 화면별 베이지/회색/코랄·테두리·타이포그래피가 혼합 | 흰색 카드 + 연한 회색 캔버스 + 일관된 타이포그래피·톤 |
| 기능보다 장식 티켓·영문 표어가 강조 | 검색과 행사 카드 중심. 데스크톱 안내 영역은 행사→부스→위치의 사용 순서, 모바일은 생략 |
| 공용 버튼·필드 크기와 라운드가 다름 | 기본 버튼44px·필드46px, 동일 테두리·포커스·모서리 |
| 행사·부스·판매정보 카드의 시각적 관계가 약함 | 제목→핵심값→주의상태→출처→행동 순서, 공통 흰색 카드·간격 |
| 보조 문구가 작거나 흐림 | 본문14~16px, 보조12px 중심. 핵심 제목20px 이상, 선택한 색 조합의 대비 검증 |
| 이미지가 없는 카드에 큰 빈 영역 | no-image 압축 카드 유지·정돈, 혼합 목록의 카드 내부 강제 빈 높이 완화 |
| 관리자 페이지와 공개 페이지가 시각적으로 혼합 | 공개는 카테고리색, 콘솔은 차분한 슬레이트 블루. 사이드바·현재 메뉴·폼·공개 작업 분리 |
| 크리에이터 홈의 통계가 ‘—’로 고정 | 미연결 통계 삭제, 실제 행사/부스/예약/POS 경로 안내 4개 카드 |

## 색상과 글자

- 캔버스 `#f6f7f9`, 카드 `#ffffff`, 본문 `#202c3b`, 보조 `#5f6b7a`.
- 서브컬처 `#b84532`, 박람회 `#285faf`, 축제 `#176851`.
- 콘솔 주요 작업 `#315b82`, 키보드 포커스 `#2167b0`.
- 성공/주의/위험/정보는 카테고리 색과 분리합니다. 취소·품절·경고 문구와 원래 상태 계산은 바꾸지 않습니다.
- 시스템 한글 폰트 스택을 사용하고 외부 웹폰트/폰트 파일/새 UI 라이브러리를 추가하지 않았습니다.
- 선택된 텍스트 색/배경16조합을 최소4.5 대비로 검사했습니다. 이것이 전체 WCAG 인증이나 실물 기기 접근성 검사 완료를 의미하지는 않습니다.

## 화면별

공개 헤더는 로고·3분야·예약·서비스 메뉴를 유지하고 모바일에서도 모든 분야를 노출합니다. 준비 중 분야는 기존대로 안내합니다. 히어로에는 검색을 우선하고 데스크톱 오른쪽에 3단계 이용 안내를 둡니다. 원문 포스터는 잘라내지 않고 `contain`으로 표시합니다.

행사 상세는 v9의 방문일·전시관·공통 검색을 그대로 유지한 채 요약/선택/결과를 구획합니다. 미승인 정보·이미지를 추가 노출하지 않습니다. 부스 목록의 실제 판매·지도 행동, 공개 정보 수와 전수 미보장 문구를 유지합니다.

판매정보 드로어는 흰색 헤더·연한 배경·독립 상품 카드로 나눕니다. 제목/가격/품절/취소/행사 관련성과 재확인 경고를 유지합니다. 원문·추가 안내는 기존 상세 펼치기, 키보드 초점·닫기·뒤로가기는 기존 동작입니다.

배치도는 컨트롤·범례·검색 결과·지도 프레임만 정리합니다. SVG 도형, 터치·핀치·전체화면, 날짜별 참가 매핑, 공개·사용 승인 검사는 변경하지 않습니다.

관리자는 수집→참가부스·판매정보→검토·공개 안내, 검토 배지, 공개 영역, 폼을 통일합니다. 수집·공개 동작과 저장 핸들러는 바꾸지 않았습니다. 크리에이터 홈은 기존 네 작업으로 가는 카드이며 추가 통계 API를 호출하지 않습니다.

## 모바일·예외

1440/768/390/320 폭에서 공개14개 화면 종류의 정적 DOM을 검사합니다. 관리자 넓은 표는 내부 가로 스크롤로 유지하며 데이터 열을 숨기지 않습니다. 모달과 지도에서 중요한 경고를 감추지 않습니다. reduced-motion/forced-colors 규칙과 키보드 포커스를 포함합니다. 전체 폼은 16px 입력 텍스트를 사용합니다.

## 변경 방식

`styles/polish.css`는 **한 번, 마지막**에 불러오는 명시적인 시각 레이어입니다. 옛 feature CSS는 상태/기하/동작을 보유하며 새 파일이 색상/서체/간격을 덮습니다. 이후 외형 변경은 이 레이어 또는 공통 토큰에서 수행하고, 각 화면마다 새 덮어쓰기 파일을 추가하지 마세요. 이 릴리스는 기존 CSS를 전면 삭제하는 리팩터링이 아닙니다.

서비스 소스 변경: `main.tsx`, `styles/tokens.css`, `styles/polish.css`, `PublicLayout`, `ConsoleLayout`, `DiscoveryPage`, `categories`, `CatalogPublicPage`, `Shared`, `CatalogAdminPage`, `CreatorPages`. 나머지는 검증·미리보기·문서입니다.

## 한계

색상·간격·소스 함수·정적 DOM 검사 결과입니다. 실제 React/라우터·로그인·DB·R2·Codex·실물 휴대전화 테스트는 아닙니다. 디자인 미리보기에 나온 행사·상품·이미지는 가상 데이터와 저장소 예시 자산이며 실제 수집 결과로 DB에 넣지 않습니다.
