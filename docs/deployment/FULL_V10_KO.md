# v10 배포 안내

기준: 전체 v9. 이번 변경은 프런트 디자인·기존 작업 링크 안내이며 **백엔드/DB/수집기와 데이터 계약의 변경이 없습니다.**

## v9에서 반영

코드 백업/브랜치 생성 → 변경 diff 확인 → 프런트 의존성 설치/lint/build → 스테이징 확인 → 프런트 배포 순서입니다. 운영 v9의 백엔드·DB·수집기를 디자인 변경만으로 재시작하거나 스케줄을 재등록할 필요는 없습니다. 이전 버전에서 한 번에 올라오는 경우에는 v9까지의 설정·SQL001~009·모델 변경을 먼저 적용하세요.

```powershell
cd frontend
pnpm install --frozen-lockfile
pnpm lint
pnpm build
```

기존 `VITE_API_BASE_URL`과 호스팅 설정을 유지합니다. 새 의존성·환경변수·데이터 마이그레이션은 없습니다. 이 환경에서는 전체 빌드를 완료하지 못했으므로 미리보기만 보고 운영 배포하지 마세요.

## 스테이징 수락 기준

1. 서브컬처 실제 데이터 조회와 준비 중 두 탭, 필터·기간·검색·페이지 및 직접 링크.
2. 모바일320/390, 태블릿768, PC1440에서 헤더·폼·표 내부 스크롤·모달·메뉴 조작.
3. 같은 방문일·전시관·검색의 부스→지도→판매정보·뒤로 가기·공유·스크롤 복원.
4. 중요 개최 상태/품절/취소/미확인/부분 수집 안내가 디자인 때문에 누락되지 않음.
5. 승인된 이미지·원본 포스터 비율·이미지 없음·지연/오류에서의 대안·출처 링크.
6. SVG 실제 도형·핀치·포인터·키보드·전체화면·초점 복귀. 색만으로 미연결을 구분하지 않음.
7. 카카오 로그인, ADMIN/CREATOR 가드, 폼 validation·저장 중·실패·미저장 경고. 크리에이터 네 작업 링크.
8. 기존 예약·재고·POS·이미지 업로드 업무 화면의 기능과 읽기전용 상태. 실제 결제/정산을 추가한 것이 아님.

## 미리보기/되돌리기

`preview/v10/index.html`은 가상 데이터의 독립 디자인 미리보기입니다. 새 시안에 제시된 수치·상품은 DB에 자동 저장되지 않습니다. 프런트만 v9로 되돌릴 수 있으며 DB 롤백은 필요하지 않습니다. 실제 외부 배포나 GitHub push는 패키지 제작 과정에서 수행하지 않았습니다.
